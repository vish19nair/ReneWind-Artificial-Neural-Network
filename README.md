Project Overview
• Objective: Build and tune classification models to predict generator failures before a breakdown occurs, optimizing decisions around timely repairs versus costly replacements.
• Company Context: "ReneWind" collects confidential, ciphered sensor data from wind turbines to improve energy production machinery and cut maintenance expenses.
Dataset Details
• Features: 40 ciphered predictor variables collected from machine sensors.
• Observations: Varies slightly by specific repository iteration, commonly featuring 40,000 training observations and 10,000 test observations (or 20,000 training / 5,000 test in alternate versions).
• Target Variable: Binary classification where 1 indicates a failure and 0 indicates no failure
